CONCEPT

「居場所があるのに、見つからない」を減らす。

地域には、子ども食堂、フリースペース、夜の居場所、学び場、ユースセンターのような場が点在しています。 でも、その情報はバラバラで、古かったり、雰囲気がわからなかったり、 「自分に合うか」が判断しづらいことが多いです。
このアプリは、居場所の情報を集めるだけでなく、その人に合う場へつながる入口をつくります。

🧭

迷わない

今日行ける場所、今週行ける場所が見つかる。 探し回る負担を減らします。

🌿

合う場所が見つかる

親子向けか、一人で行けるか、静かか、にぎやかか。 雰囲気で選べます。

🤝

地域とつながる

利用者には入口を、団体には出会いを。 地域の支援資源が届く仕組みをつくります。

WHY

検索すれば出てくる、では足りない。

本当に必要なのは「情報」そのものではなく、 行ってみようかなと思える状態です。

いま起きていること

  • • どこに行けばいいかわからない
  • • 情報が古い、開催しているかわからない
  • • 親子で行けるか、一人で行けるかが不明
  • • 初めての場所は雰囲気が読めず不安
  • • 団体の存在を知っても、連絡の仕方がわからない

このアプリで目指すこと

  • ✓ 今日行ける場所をひと目で見せる
  • ✓ 雰囲気や対象で選びやすくする
  • ✓ 親子向けとユース向けを分かりやすく分ける
  • ✓ 写真や説明で安心材料を増やす
  • ✓ 将来的に団体へ直接つながる導線を整える
FOR WHO

こんな人のためのアプリです。

「親子で行く場所」だけではなく、 中高生やユースが一人で行ける場所も見つけやすい設計を目指します。

親子で居場所を探している人

子ども食堂やフリースペースなど、 親子で安心して行ける場所を探したい人に。

一人で行ける場所を探す中高生・ユース

親と一緒ではなく、自分のペースで行ける居場所、 干渉されすぎない場を探したい人に。

地域の居場所団体・支援団体

良い活動をしていても、必要な人に届きにくい。 そんな団体の発信を支えるために。

FEATURES

最初に必要なのは、多機能ではなく、ちゃんと届くこと。

MVPでは、複雑なSNS機能よりも、 「見つかる」「選べる」「つながれる」を優先します。

① 今日行ける場所がわかる

「今日」「今週」「夜」など、今のタイミングで使える居場所を優先表示します。

  • ✓ 今日・今週の開催情報を優先表示
  • ✓ 現在地から近い場所を見つけやすい
  • ✓ ユース向けも親子向けも同時に見られる

② 雰囲気で探せる

「この子に合いそう」「自分でも行けそう」で選べるようにします。

  • ✓ 静か・少人数・にぎやかで絞り込み
  • ✓ 一人参加OK / 親同伴OKで分ける
  • ✓ 年齢・料金・時間帯でも検索

③ 初めてでも安心できる

行く前に不安が減ることを重視します。

  • ✓ 写真で場の雰囲気がわかる
  • ✓ 対象年齢や参加のしやすさを表示
  • ✓ 「行きたいかも」で保存できる

④ 団体につながる導線をつくる

いきなり複雑なDM機能は持たせず、まずは連絡しやすい入口を整えます。

  • ✓ Instagram・LINE・公式サイトへの導線
  • ✓ 問い合わせ先がひと目でわかる
  • ✓ 将来的にアプリ内連絡機能も検討

今後の拡張

将来的には、アプリ内で団体代表者に直接メッセージを送れる仕組みも検討します。

FLOW

“行く”の前に、“見てみる”から始める。

強く背中を押すのではなく、 その人が自分のペースで一歩を選べる導線を大切にします。

1

開く

今日行ける場所、今週つながれる場所をまず見る。

2

選ぶ

親子向けか、一人で行けるか、雰囲気で選ぶ。

3

保存する

今すぐ行かなくても「行きたいかも」で残しておける。

4

つながる

外部リンクや今後の連絡機能を通じて、団体へ接続する。

PARTNERS

利用者だけでなく、地域の団体や協賛企業にも価値がある。

このアプリは、地域で場をひらいている人たちの活動を、 必要としている人へ届きやすくするための仕組みでもあります。

掲載団体にとっての価値

良い活動をしていても、必要な人に届かなければ出会いは生まれません。 このアプリは、地域団体の“見つかりにくさ”を減らします。

  • ✓ 地域の利用者に見つけてもらいやすくなる
  • ✓ 活動日時や雰囲気を分かりやすく発信できる
  • ✓ 連絡先を一箇所に整理できる

協賛企業・団体にとっての価値

地域の子ども・若者・親子を支えるインフラづくりに関わることは、 企業や団体にとっても地域貢献の可視化になります。

  • ✓ 地域支援への具体的な参画になる
  • ✓ 居場所づくりを支える社会的意義が高い
  • ✓ 地域との接点や信頼形成につながる
今後の拡張構想

気になる団体の代表者に直接連絡できる仕組みも視野に入れています。

ただし、最初から複雑なDM機能を入れるのではなく、 まずはLINE・Instagram・Webサイトへの導線で、使いやすく安全な接続を実現します。

その後、運用負担や安全性を見ながら、 アプリ内での問い合わせ機能や、団体代表者への直接連絡機能へと発展させる想定です。

地域の居場所を、もっと見つかりやすく。

利用したい人にも、場をひらいている人にも、支えたい企業にも。
この構想に関心のある方、掲載や協賛に興味のある方は、ぜひつながってください。
