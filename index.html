CONCEPT

「どこに行けばいいかわからない」を減らす。

不登校支援や居場所の情報は、あっても散らばっていて、古かったり、雰囲気がわからなかったりします。 このアプリは、情報をただ並べるのではなく、親子が次の一歩を選びやすくすることを目指します。

📅

今日行ける

「今から行ける場所」「今週参加できる会」がすぐ見つかる。 予定と気持ちの両方に合わせて選べます。

🌿

雰囲気で選べる

静か・少人数・親同伴OKなど、 子どもに合うかどうかを感覚的に判断しやすくします。

🤝

初めてでも安心

写真や口コミ、対象年齢などを見て、 「行ってみようかな」と思える情報をそろえます。

FEATURES

最初にほしい機能は、たくさんではなく、ちゃんと使えるもの。

MVPでは、検索機能を盛りすぎず、 「情報→判断→一歩」までの流れをなめらかにすることを優先します。

① 今日行ける場所がわかる

検索させる前に、まず提案する。行動のハードルを下げるためのホーム画面です。

  • ✓ 今日・今週の開催情報を優先表示
  • ✓ 現在地から近い場所を表示
  • ✓ オンライン参加も同列で見せる

② 雰囲気で探せる

「どこが良いか」ではなく、「この子に合うか」で探せるようにします。

  • ✓ 静か・少人数・にぎやかで絞り込み
  • ✓ 年齢・料金・親同伴可でも検索
  • ✓ 地図と一覧をセットで表示

③ 初めてでも安心できる

初参加の不安を減らすために、心理的安全性を支える情報を重視します。

  • ✓ 写真で場の雰囲気がわかる
  • ✓ 対象年齢や参加しやすさを表示
  • ✓ 口コミや「行きたいかも」保存機能

④ 団体が更新しやすい

運営側だけが頑張る設計では続かないため、掲載団体が自分で情報更新できる構造にします。

  • ✓ 日時・写真・タグを簡単入力
  • ✓ 更新日時を自動表示
  • ✓ 古い情報は優先度を下げる
PREVIEW

画面の雰囲気は、こんなイメージです。

やわらかい色、余白のあるUI、圧の少ない文言で、 「検索する」より先に「見てみる」ができる設計を目指します。

💬 行きたいかも

FLOW

“行く”の前に、“見てみる”から始める。

子どもにも親にも負担をかけすぎないよう、 このアプリは強く背中を押すのではなく、一歩手前を支える設計を想定しています。

1

アプリを開く

まずは「今日行ける場所」や「今夜つながれる場所」を見る。

2

雰囲気で選ぶ

静か・少人数・親同伴OKなど、その子に合う条件で絞る。

3

気になる場所を保存

すぐに行かなくてもいい。「行きたいかも」で残しておける。

4

行けそうなら一歩

初参加でも安心できる情報を見ながら、無理のない形でつながる。

この構想を、実際のアプリに。

まずは小さく、地域を絞って、ちゃんと使われる形で始めたい。
不登校親子の「次の一歩」を支えるプロダクトとして、ここから具体化していきます。
